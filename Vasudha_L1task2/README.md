# vasudha-task2
Personal Portfolio Website

Overview

This project is a Personal Portfolio Website developed as part of the Oasis Infobyte Web Development Internship (OIBSIP).

The website showcases my skills, projects, educational background, and interests in a clean and organized manner, helping create a professional online presence.

Features

- Responsive layout
- Modern and clean design
- About Me section
- Skills section
- Projects section
- Contact section
- Smooth navigation

Technologies Used

- HTML5
- CSS3

Purpose

The purpose of this project was to apply front-end web development concepts by creating a portfolio website that effectively presents personal and professional information.

Learning Outcomes

Through this project, I gained experience in:

- Structuring web pages using HTML
- Styling web pages using CSS
- Creating responsive layouts
- Improving UI/UX design skills
- Organizing content for professional presentation
